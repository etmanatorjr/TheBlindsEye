Background

About the Project

Each of us took on a different role. Karim built this website. Selim designed and built a LEGO-based walking stick that emits a sound when an obstacle is detected. Mahmoud built an Arduino-powered stick that uses vibration instead.

Today we're testing both side by side to find out which feedback method — sound or vibration — helps a person navigate obstacles more effectively.

Research

Question & Hypothesis

Testable Question

Is vibration or sound more effective when a walking stick detects an approaching obstacle?

Our Hypothesis

We think vibration will be more effective. In noisy or crowded places, a buzzer can be hard to hear — but you can always feel a vibration.

Methodology

Variables

Independent

Number of obstacles placed in the path

Dependent

Time taken to navigate past all obstacles

Controlled

Same area · same person · same obstacle layout

Prototypes

The Two Designs

Prototype A
Sound

LEGO Buzzer Stick

Built by Selim

Uses a buzzer to emit sound when an obstacle is detected. Selim had a head start, allowing more time for testing and refinement.

  • Finding the right battery type
  • Missing vibration sensor initially
  • Weight distribution issues
  • Fixed by centering the battery
Prototype B
Vibration

Arduino Vibration Stick

Built by Mahmoud

Uses vibration motors controlled by an Arduino for tactile feedback. Built just one day before the competition — an impressive effort.

  • Solder wouldn't stick to cables
  • Switched to screw-in terminals
  • Taped exposed wires for safety
  • Cardboard housing glued to stick
Testing

3 Experiments

We ran three trials, each in the same space with the same person, to keep the comparison fair.

1

Single Obstacle — Open Path

One obstacle in a clear corridor. Tests basic detection speed and reaction time.

2

Multiple Obstacles — Straight Line

Several obstacles arranged in a row. Tests how well each stick guides through repeated alerts.

3

Scattered Obstacles — Busy Environment

Random layout simulating a crowded area, where sound alerts may be less reliable.
