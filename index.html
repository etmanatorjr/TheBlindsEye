Background

About the Project

Each of us took on a different role. Karim built this website and Mahmoud designed and built an Arduino-powered walking stick that uses both vibration and a buzzer to alert the user when an obstacle is detected.

Our goal is to show how vibration and a buzzer can effectively guide visually impaired users through obstacles in everyday environments.

Research

Question & Hypothesis

Testable Question

Can vibration and buzzer feedback effectively guide a visually impaired person around obstacles?

Our Hypothesis

We believe vibration is a reliable feedback method because it works regardless of noise levels — you can always feel it even in a crowded environment.

Methodology

Variables

Independent

Type of feedback component

Dependent

Time taken to navigate past all obstacles

Controlled

Same area · same person · same obstacle layout

Experiment

Busy Environment

Multiple obstacles are placed in front of the user in a random, irregular path that is deliberately difficult to navigate. The obstacles are not in a straight line — they are scattered in unpredictable positions, forcing the user to constantly change direction. The walking stick must detect each obstacle in time and alert the user through vibration and a buzzer so they can avoid it without seeing it.
